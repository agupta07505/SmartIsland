This document reflects the **Smart Island v6.0.0** product baseline, released on **August 29, 2026**.

## 🔍 Detailed Analysis

### 1. What? (O que?)
**Smart Island** is a lightweight Android overlay utility. 
- It adds a small, interactive, animated floating "pill" near the status bar built with a clean Material 3 Expressive UI and **Ultra-Fluid Spring Physics** (`stiffness = 520f`, `dampingRatio = 0.72f`).
- It supports **Tap Anywhere on Expanded Cards to Open Target App**: Neutral taps on expanded cards outside action buttons launch the corresponding app/system screen and collapse the island.
- It features an **Auto-Hide Pill Inactivity Timer**: Configurable countdown (1s–60s) with 1-tap presets and invisible touch target allowing tap-to-awaken even when notifications are active.
- It provides **Landscape Mode Visibility Controls**: Opt-in toggle to keep the island active and dynamically repositioned during device rotation, or auto-hide for distraction-free gaming.
- It provides **Island Opacity & Transparency Controls**: Continuous opacity adjustment (20% to 100%) with 4 quick presets (Solid, Dark, Glass, Clear) and drop shadow depth.
- It supports **13 Dynamic Island Modes**: Notification (with **Inline Reply**), Timer, Stopwatch, Music (with wavy seek bar), Incoming Call, Battery (Charging, Low Battery &le; 20%, Battery Saver), Live Activity (delivery & rideshare), Turn-by-Turn Navigation, Download/Upload, Wi-Fi Hotspot, Bluetooth, Flashlight, and Screen Recording.
- It features an **Inline Reply Input Engine**: Direct typing inside the expanded card with dynamic WindowManager focus switching and `RemoteInput` pending intent execution.
- It provides a **High-Performance SQLite Notification History Hub**: Top-level `LazyColumn` virtualization with background `AppIconMemoryCache`, search, filter by app/mode, inspect details, and bulk **Delete by App**.
- It includes an **OEM Device Rules Engine**: Vendor-specific autostart & battery optimization guidance for Xiaomi/HyperOS, Samsung OneUI, OnePlus/Oppo/Realme, Huawei, Vivo, and Asus.
- It includes an **Interactive 5-Gesture Guide**: Responsive 2-column cards for Single Tap, Swipe Up, Hold + Swipe Up (300ms haptic), Swipe Down, and Swipe Left/Right.
- It monitors Wi-Fi Hotspot status via `HotspotUtil`, displaying connected client counts parsed from system tethering notifications, SSID info, and quick turn-off controls.
- It renders **Live Activity cards** for delivery and ride tracking apps via `LiveActivityParser`, with dynamic per-app brand color tinting and real-time status updates.
- It shows **Download/Upload progress** (`DownloadExpanded`) with real-time progress bars, transfer speeds (MB/s), custom transfer icons, and sync suppression.
- It provides **Turn-by-Turn Navigation** guidance (`NavigationExpanded`, `NavigationParser`) showing next instruction, distance remaining, ETA, and maneuver arrows.
- It intercepts system notifications, suppresses system shade duplicate popups via `NotificationFilter`, and presents them in a custom, expandable Compose UI.
- It provides **granular per-app notification and sound controls** under Notifications & Privacy settings.
- It automatically hides when in landscape mode (`IslandOrientationListener`) to avoid interrupting gaming or video streaming.
- It provides opt-in lock screen status viewing with sensitive notification masking controls.
- It provides configurable shortcuts to launch up to eight selected apps from the expanded island.
- It supports customizable dimensions, position, corner radius, and custom RGB indicator colors for all 13 modes.

### 2. Why? (Por que?)
- **Better Notifications**: Enhances the standard Android heads-up experience by consolidating active notification cards, music playback, timers, and calls into a single, organic, and elegant interface.
- **Direct Productivity**: Inline text reply enables rapid messaging responses without switching contexts or opening the full app.
- **Premium UX**: Offers smooth morphing animations and haptic-responsive components (like the `bounceClick` modifier).
- **Privacy by Design**: All notification parsing, display, and history indexing occur strictly on-device with zero analytics or tracking SDKs.
- **Advanced Customization**: Allows users to dynamically adjust the pill's alignment, sizing, and RGB color styling to fit their specific display punch-holes or notches.
- **Learnable Gestures**: Includes an animated guide and interactive practice area for learning the island's 5 swipe controls.

### 4. Where? (Onde?)
- **Code Repository**: Hosted on [GitHub - agupta07505/SmartIsland](https://github.com/agupta07505/SmartIsland).
- **Execution Environment**: Runs locally as a background foreground service in Android's application overlay window layer (`TYPE_APPLICATION_OVERLAY`).
- **Touch Interaction Zone**: Reflection on `OnComputeInternalInsetsListener` is utilized to restrict the window's touch boundary exclusively to the physical pill area so it does not block touches to apps in the background.

---

### 5. When? (Quando?)
- **Active State**: Operates whenever the user enables the master toggle in [SmartIslandHomeScreen](file:///a:/SmartIsland/app/src/main/java/com/agupta07505/smartisland/ui/SmartIslandHomeScreen.kt).
- **Event Triggers**:
  - Automatically expands when a new high-priority notification is posted.
  - Activates a live audio visualizer when media apps are playing music.
  - Starts a green count-up timer during active phone calls.
  - Activates live countdown/elapsed progress during running timers and stopwatches.
  - Expands automatically when the device is plugged into a charger, rendering a pulsing battery icon and charging percentage.
- **Auto-Collapse**: Initiates a countdown timer after expansion; collapses back to the pill state if no user interaction is detected (automatically paused when typing an inline reply).

### 6. How? (Como?)
- **Tech Stack**: Built using **Kotlin 2.0+**, **Jetpack Compose (Material 3)**, **Dagger Hilt**, and Android System Services.
- **Settings & Persistence**: Persists user preferences reactively through **AndroidX DataStore Preferences** and notification logs in **SQLite** (`NotificationHistoryDbHelper`).
- **Component Architecture**:
  1. [SmartIslandNotificationListenerService](file:///a:/SmartIsland/app/src/main/java/com/agupta07505/smartisland/service/SmartIslandNotificationListenerService.kt): Listens to and intercepts notifications, extracts media/clock states, and determines island mode display classes.
  2. [SmartIslandOverlayService](file:///a:/SmartIsland/app/src/main/java/com/agupta07505/smartisland/service/SmartIslandOverlayService.kt): Manages the window layout metrics, handles touch-insets, coordinates collapse/expand transitions, and toggles WindowManager focus for soft-keyboard IME typing.
  3. [IslandOverlayView](file:///a:/SmartIsland/app/src/main/java/com/agupta07505/smartisland/ui/IslandOverlayView.kt): The primary UI layout handling spring animations, gestural swipes, and horizontal paging.
  4. [SystemEventReceiver](file:///a:/SmartIsland/app/src/main/java/com/agupta07505/smartisland/service/SystemEventReceiver.kt): Listens to system power status changes, updates battery charging information, and triggers/dismisses the charging island.
  5. [TimerStopwatchParser](file:///a:/SmartIsland/app/src/main/java/com/agupta07505/smartisland/util/TimerStopwatchParser.kt): Decodes clock notifications into live countdown and millisecond stopwatch states.
  6. [OemDeviceRules](file:///a:/SmartIsland/app/src/main/java/com/agupta07505/smartisland/util/OemDeviceRules.kt): Configures vendor-specific autostart and background protection rules.
- **5-Gesture Engine**:
  - **Single Tap**: Toggles collapsed pill to expand rich card details.
  - **Quick Swipe Up**: Dismisses and clears the active notification.
  - **Hold + Swipe Up (300ms)**: Clears all notifications simultaneously with haptic feedback.
  - **Swipe Down**: Opens the corresponding app inside a floating system Freeform Window.
  - **Swipe Left/Right**: Switches pages between multiple active notifications/modes in the stack.

### 7. How Much? (Quanto?)
- **Financial Cost**: 0 (Fully free and open-source under GPLv3).
- **Network Overhead**: 0 bytes for core operations (optional minimal traffic strictly for user-opted GitHub release checks).
- **System Overhead**: 
  - Low memory footprint with bounded LRU icon caching and trimmed SQLite history.
  - Negligible battery drain because the service sleeps when events are idle and uses hardware-accelerated Compose rendering.
